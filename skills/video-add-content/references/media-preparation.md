# Generate files from a local MP4

Requires Python 3.10+, FFmpeg/ffprobe on PATH, and `pip install -r scripts/requirements.txt` in the agent's Python environment. First use downloads the selected open Whisper model; transcription runs locally. There are no SaaS-side AI credentials. The agent reads the transcript and performs translation and editorial writing using its own language capabilities.

1. Run `python scripts/prepare_media.py prepare <actual-video.mp4> --output <new-folder>`. Optional `--language en` fixes a known source language; default model `small` supports multiple languages. The output folder must be new. Read `transcript.json`, and inspect/play the actual source and `cover.jpg`. The cover is a frame extracted at 20% of the video, not an AI-generated illustration. If unsuitable, extract a different actual frame with FFmpeg into a fresh filename and update the manifest's cover path. Do not infer identities or substantive claims from filenames or a frame.
2. Review the transcription against audio, especially names and numbers. Correct cue text in the manifest when warranted, preserving actual timing. For poor recognition use a larger multilingual model in a fresh folder. No speech or no audio must be reported; ask for a real transcript rather than inventing captions.
3. Create `editorial.json` from `editorial-template.json`: write a factual title (<=120 characters), description (<=4000), and all cue texts in English, French, German, Italian and Spanish. Preserve the cue count, order and IDs. Translate speech faithfully; keep names and numbers accurate. All five languages are required, including a cleaned transcription for the source language. Explain uncertainty to the user; machine-generated captions require content review before publication.
4. Run `python scripts/prepare_media.py finalize --output <folder> --editorial <editorial.json>`. This validates completeness and generates five UTF-8 WebVTT files with the original timings plus `content.json`. It refuses to overwrite existing captions. Only `status=complete` proves all files were generated.
5. Upload the MP4 through its normal upload form first. Then upload the cover and each VTT through the matching file inputs, choosing that returned video asset in each upload form. A file path is not an attachment ID. Read the page state after uploads and match actual returned `kind`, `language`, and `asset_id`. Prepare title/summary and the six attachment IDs, save if requested, and verify the persisted fields and links.

Use user-provided cover/captions instead when requested. Do not regenerate or overwrite supplied files. A partial failure leaves local intermediates; report exactly which stages completed and recover into a fresh output folder. Never claim a local VTT path is an uploaded URL until the app confirms it.
